# SJZ 三键音乐键盘网页端

此网页对应 SJZ PyQt V1.15，包含音乐星球、键位设置、灯光设置、设备维护、关于五个页面。最新版曲库保存在 `public/data/music-catalog.json`；网页项目只保留当前 25 首曲目，不收录历史曲库备份。

## 本地运行

```powershell
python -m http.server 8788 --directory public
```

在 Chrome 或 Edge 打开 `http://localhost:8788`。WebHID 需要安全上下文和用户授权；部署时也必须使用 HTTPS。点击右上角“连接”，选择 SJZ 键盘。

## 功能

- 从当前曲库试听、搜索、拖放并写入 K1～K3；V2 曲包包含曲目编号，设备维护可显示已保存的歌曲。
- 读取、编辑、保存每颗键的键值、播放暂停或旋转陀螺角色，支持鼠标灵敏度、水平灵敏度和每圈速度。设备维护显示键盘中已经保存的角色。
- 读取、编辑、保存按下点亮、常亮、流水灯，以及三个按键的颜色。亮度固定 50%。
- 选择 PyQt 使用的 `.enc.hex` 加密 APP 升级包，在浏览器本地解密验证后通过 USB 更新。切换到 BOOT 后如需新授权，页面会显示“连接 BOOT 并继续”。只有设备端 CRC32 校验通过且 APP 稳定重连，才报告升级完成。

升级网页内置的 AES 密钥仅用于与现有 PyQt 加密包兼容，属于文件格式门槛，不构成防逆向的强安全保护。
